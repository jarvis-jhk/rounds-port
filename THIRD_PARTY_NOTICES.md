  Font License 1.1. Used for the renderer's built-in text. Text of the license:
  `licenses/OFL.txt`.

  setup-header table of [fsbex](https://github.com/astral4/fsbex)

  about 240 in total) with its license text is listed in
  `licenses/RUST_DEPENDENCIES.txt` (generated per release by

## Dynamically linked

- **SDL2** (https://libsdl.org), zlib license, (c) Sam Lantinga and contributors.
  - Linux: the system's `libSDL2-2.0.so.0` is used (SDL >= 2.26). A package
    built with `scripts/package-linux.sh --bundle-sdl` carries that library in
    `lib/` together with `licenses/SDL2-LICENSE.txt`.
  - Windows: the official SDL2 2.32.10 mingw release `SDL2.dll` ships next to
    `rounds-port.exe`; license text in `licenses/SDL2-LICENSE.txt`.

## Windows runtime

The Windows executable is cross-compiled with
[llvm-mingw](https://github.com/mstorsjo/llvm-mingw) and statically contains
the mingw-w64 C runtime (public domain / ZPL 2.1), LLVM's libunwind and
compiler-rt builtins (Apache-2.0 WITH LLVM-exception) and the Rust standard
library (MIT OR Apache-2.0).

## Online play

Online play uses [Warpzone](https://github.com/jarvis-jhk/warpzone)
(`warpzone-core`, linked as a Rust crate; see the crate list above) and
[GGRS](https://github.com/gschup/ggrs) (MIT OR Apache-2.0) for rollback.
